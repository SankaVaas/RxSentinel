# Clinical Disclaimer

RxSentinel is a **research and portfolio demonstration project**. It is:

- **Not** an FDA-cleared or CE-marked medical device.
- **Not** validated for clinical decision-making in a real care setting.
- **Not** a substitute for pharmacist or physician judgment.

If adapted toward real clinical use, this system would need to be evaluated
against FDA's Software as a Medical Device (SaMD) framework and Clinical
Decision Support (CDS) guidance, undergo clinical validation studies, and
implement far more rigorous data governance (PHI handling, BAA-covered
infrastructure, HIPAA-eligible hosting) than this scaffold includes.

Every finding surfaced by this system carries its evidence and source
citation specifically so a claim is never presented to a user without a way
to independently verify it — but that transparency does not substitute for
clinical validation.
